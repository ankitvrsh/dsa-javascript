# Introduction to Functions

## DRY Principle

DRY stands for Don’t Repeat Yourself.  
DRY Principle says that if we have already done a task, why do we want to do it again and again.

## Debugging Functions

In JS, if a function doesn’t explicitly return a value, it automatically returns undefined.  
Example:  
console.log() function returns undefined.

## Arguments and Parameters

While defining the function, input values are called as Parameters.  
While calling the function, input values are called as Arguments.

Argument is something that is passed.  
Parameter is something that is expected or defined.
