# Best Case | Average Case | Worst Case

For every different type of cases, we have some notations.

```text
Best Case     Ω (Big Omega)
Average Case  Θ (Big Theta)
Worst Case    O (Big Oh)


Worst Case actually denotes how bad an algorithm can perform.

Average Case denotes how an algorithm performs on an average for different 
variety of inputs.

Best Case represents that for some specific best cases, we will be having 
a bare minimum complexity that atleast will be matched by our algorithm, that 
if our algorithm wants to perform good, how good it can be.
```

For representing the rate of growth in terms of highest degree terms, we use these notations.

## General notion when we talk about complexity

Whenever we talk about complexity of a function, we generally care about the worst case time complexity only because worst case is going to be the worst possible thing that can happen while algorithm execution.

NOTE:  
There can be cases that all the three complexities (Best Case, Average Case, Worst Case) are same or maybe any two of them are same.
