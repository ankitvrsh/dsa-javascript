# Problem

Given two numbers a and b, find the greatest common divisor of a and b.

## Solution

Greatest Common Divisor ⇒ GCD ⇒ HCF ⇒ Highest Common Factor

Input: 28 and 24  
Output: 4

```text
28: 2 * 2 * 7
24: 2 * 2 * 2 * 3

Common factors: 2 * 2
GCD: 4
```
