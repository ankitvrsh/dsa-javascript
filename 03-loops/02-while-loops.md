# while loop

What is the difference between while and if?

if will only check the condition once, doesn’t matter if the condition is true or false.  
Whereas, while loop checks the condition again and again, till the time it becomes false.

## Entry Controlled and Exit Controlled

while loop is entry controlled.  
Entry controlled means, before we enter the while loop, we check the condition.

do while loop is exit controlled.  
We always enter in the do while loop, when we are going to exit, that part is going to actually maintained by the condition.
