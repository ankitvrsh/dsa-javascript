# Problem - Reduce to 1

Given a positive non-zero number n, calculate the minimum number of steps to reduce n to 1.  
For this reduction, we can do the following operations on n:

- If n is divisible by 3, divide by 3.
- If n is divisible by 2, divide by 2.
- Subtract 1 from n.

Example:  
Input: n = 10  
Output: 3
