# Basics of JavaScript

JS is technically a multi-paradigm programming language.  
In JS, we can do functional programming, procedural programming and object-oriented programming as well.

We call the code of a software as a program.  
When we want to run this program, this program will get loaded inside the RAM and becomes a process.

RAM is primary storage area.

Program in a running state is called Process.  
If a program is loaded as a process, it gets some memory allocated to it from the RAM.

## Keywords

In a programming language, few words are reserved by the language for its own purpose.  
We cannot change their meaning or repurpose them for a different usecase.  
Example: let, for, const, if, else, return, etc.

## Variables

To store values inside a program, we can use variables.  
Variables are memory buckets that stores our values and has a name as well.  
Inside variables, we can store data.

There are three ways to declare variables in JS using the var, let, and const keywords.

```js
var marks = 90;
let score = 5;
const age = 24;
```

One complete instruction is called Statement.
