# Special Characters and Comments in JS

## Escape characters or Escape sequences

```text
\n ⇒ new line character
\t ⇒ tab
\\ ⇒ backslash
\b ⇒ backspace
\r ⇒ carriage return
\” ⇒ double quote
\f ⇒ form feed
\’ ⇒ single quote
```

## Comments

Comments are a piece of code that is for documentation purpose.  
The programming language will just avoid comments during execution.
